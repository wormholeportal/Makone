# onboarding/ — the first minute

Nobody reads your instructions. The first 30 seconds either teach the verb or
lose the player.

| page | what it fixes |
|---|---|
| `first-30s.md` | the opening doesn't land — use the core verb 5+ times, close one feedback loop, win one micro-victory |
| `progressive-disclosure.md` | everything unlocked at once — one new idea per level, then combine |
| `tutorial-types.md` | mixing implicit / explicit / contextual / optional / mandatory tutorials into mush |

See also `game/axioms/play-teaching.md` — the axiom these three implement.
