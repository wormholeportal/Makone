# audio/ — the channel you keep forgetting

Muted, most of these worlds lose half their impact. Sound is a feedback channel
first and a mood layer second.

| page | what it fixes |
|---|---|
| `feedback-sound.md` | events with no sound — every meaningful event gets its own |
| `music-tension.md` | one static BGM loop — drive music from the game's tension state |

Pairs with `game/feel/juicing.md`: sound is one of the stacked channels there.
