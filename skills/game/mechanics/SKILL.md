# mechanics/ — where depth comes from

Feel makes a second feel good. Mechanics make the next ten minutes worth
playing. Reach here when the game is responsive and still boring.

| page | what it fixes |
|---|---|
| `interesting-decisions.md` | choices with a dominant option — make trade-offs incomparable |
| `risk-reward.md` | no tension — a safe small prize and a risky big one, always both on the table |
| `second-order.md` | depth by piling on content — get it from combinatorial rule space instead |
| `resource-economy.md` | one currency, one optimal line — 2–4 competing scarcities |
| `reward-schedules.md` | rewards feel mechanical — variable ratio beats fixed |
| `difficulty-arc.md` | flat pacing — teach → master → pressure → catharsis → new lesson |
| `intrinsic-motivation.md` | play driven only by numbers going up — autonomy / mastery / relatedness |
| `pickup-consent.md` | a pickup changes the build against the player's will — give them consent |
